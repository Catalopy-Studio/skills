# LLM Skills

Catalog of 144 reusable agent skills collected for Catalopy Studio.

## How to use this table

- Invoke a skill with its command, for example $algorithmic-art.
- The usage column is the skill description from its SKILL.md.
- The example column is a generated starting prompt; read the skill instructions for its full workflow and constraints.
- Third-party licenses and source notices remain inside the individual skill directories.
